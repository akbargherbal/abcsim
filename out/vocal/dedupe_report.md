## Rescue pass

The rarity-weighted alignment can stop early when the same melody has enough
rhythmic variation. This second pass is only for pairs with z >= 10 that fail
the weighted coverage rule. It accepts a pair only when:

- an **unweighted** local alignment covers >= 0.5 of the shorter song, and
- a whole-song global alignment scores >= 0 (0 = break-even).

Calibration from the listening sheet: `suno-0089` / `suno-0108` was marked
**same** (uniform coverage 0.96, global score +3), while the two controls marked
"unsure/different" scored -523 and -353. The global-score floor is what rejects
shared sections that happen to cover half of a short song.

## Voice mode and limitations

- This run compares only the **lead** voice (most notes). 82 songs have `Ins`
  as lead; cross-lead duplicates (Ins-lead vs Vocal-lead) can be missed.
  `build_index.py --voice vocal` + `run_similarity.py --voice vocal` build a
  vocal-only index for a later comparison. Run `compare_cluster_runs.py` to
  write `out/vocal/clusters_lead_vs_vocal.md`; vocal-only clusters are
  candidates for human review, never automatic merges.
- Representative choice uses `validation.csv`: non-empty Vocal lead first,
  then no flags, then bar count nearest 146, then lowest id.
- The corpus has no lyrics and no ratings, so these are melodic near-duplicates,
  not a claim about released versions.
